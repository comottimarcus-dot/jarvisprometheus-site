01 / EDGE SIGNALS

One pump. Three states.

An ESP32-C3 with a display emulates pump P-204. A physical button selects NORMAL, WARNING or CRITICAL. The node sends explicitly simulated temperature, vibration, pressure, motor current, speed and maintenance signals to the Core.

02 / EXPLICIT AMD ANALYSIS

Ask for analysis.

A status check reads local telemetry without GPU inference. A separate analysis request reaches Qwen3-32B on one AMD Instinct MI300X through the existing X6 runtime, dispatcher and executor.

03 / HUMAN REVIEW

Keep the scope honest.

Local rules determine severity. The model reviews the supplied signal context, and the gate accepts only bounded inspection checks. If newer samples arrive during inference, the result is historical and current recommendations are blocked.

HOW IT CONNECTS

The device speaks. The Core governs.

Voice & edge telemetry→Bounded Core tools→X6 / AMD analysis→Governed voice reply

The C3 publishes authenticated MQTT telemetry. Xiaozhi uses the existing AssemblyAI bridge to call Core tools. Only explicit analysis requests use AMD; local status reads remain local. Firmware holds no cloud credentials and never chooses a GPU or contacts vLLM directly.

Built for a technician's next question.

Machine alerts can leave operators switching between screens and context. FORGE offers a spoken view of a pump's condition and a separate, traceable request for model review.

The prototype validates the integration and its response boundaries. A future plant pilot would measure investigation time, operator comprehension and maintenance outcomes; no such improvement is claimed from this bench demonstration.

A test rig with explicit limits.

All pump signals are simulated. Demo thresholds are not certified industrial operating limits. There is no physical actuation path, autonomous GPU selection, demonstrated physical failover or eight-GPU execution.

FORGE adds the industrial contracts, C3 emulator, ingest, governance gate and evidence capture. Core/X6 and the voice transport are pre-existing components. The source bundle documents that boundary and the dependencies needed for live reproduction.
