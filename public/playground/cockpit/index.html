# Project Title
PROMETHEUS: Blast Radius Zero AI Agent Sandbox

## Elevator Pitch
Zero-blast-radius autonomous agent containment pipeline bounded by Vultr Serverless Inference and sealed cryptographic proof. Discovery is not authority.

## Challenge Category
Vultr Hackathon · Challenge 1: Blast Radius Zero

## What It Does & Problem It Solves
When autonomous AI agents evaluate untrusted repositories and code, inspection is completely decoupled from execution. Every run is governed by least privilege, strict time, memory, and network bounds via Vultr Serverless Inference, human authorization gates, ephemeral container isolation, SHA-256 evidence manifests, and real-time containment of adversarial egress and file tampering.

Our thesis: discovery is not authority. PROMETHEUS turns agent containment into a verifiable governance property, not a promise.

## Live Vultr Infrastructure (São Paulo)
- Vultr Cloud Compute (vc2-1c-1gb) in São Paulo region (sao).
- Zero public listening TCP ports (ss -tlpn verified).
- Local Broker IPC: /run/prometheus-playground/sandbox-broker-v1.sock (mode 0660 root:prometheus).
- Vultr Serverless Inference: Untrusted code discovery bounded at $0.000259/run.
