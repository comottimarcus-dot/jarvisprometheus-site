Challenge 1 Security Architecture·Zero-Trust Containment Model

Blast Radius Zero: Structural Defense-in-Depth

In standard AI agent frameworks, running untrusted code creates massive blast radius risks: leaked cloud credentials, network pivot attacks, and persistence backdoors. PROMETHEUS solves this by enforcing an uncompromising four-tier defense boundary on Vultr infrastructure.

Layer 01 🌐

Sanitized Presentation Surface

Hosted on Cloudflare Pages (jarvisprometheus.space/playground). Strictly limited to static evidence playback. No browser can execute arbitrary code on the Vultr node.

Attack Surface:Zero (Static Edge)
Credentials:None in client
Layer 02 🖥️

Hardened Vultr Control Plane

Vultr VPS in São Paulo (vc2-1c-1gb). Zero public non-SSH TCP listening ports. System services talk strictly across private local AF_UNIX sockets with 0600 permissions.

TCP Ports:0 Public Ports
Transport:AF_UNIX (Local)
Layer 03 🧠

Vultr Serverless Inference

AI reasoning powered by Vultr Serverless Inference (qwen3.8-flash-next). Model is used solely to synthesize bounded experiment contracts with strict cost ceilings ($0.000259/call).

Cost Ceiling:Respected ($0.001)
Actuation:No raw execution
Layer 04 🛡️

Ephemeral Root-Owned Sandbox

Immutable Docker container managed by root broker (0660 root:prometheus). Ephemeral tmpfs, read-only rootfs, zero network interface (--network none), stripped environment, auto-destruct on exit.

Idle Containers:0 (Auto-pruned)
Network Egress:Blocked (None)

🔒 Blast Radius Zero Guarantee Matrix

🔑 Zero Secrets In Sandbox

Vultr API tokens, SSH keys, and system secrets are never mounted, injected, or passed into the container environment. A compromised dependency finds zero credentials to steal.

🚫 Zero Network Egress

Containers run with isolated network namespaces without virtual ethernet bridges (--network none). Sockets cannot connect outward to command-and-control servers.

🗑️ Auto-Destruction & Zero Persistence

Every job uses an immutable image digest. Containers exist for sub-second lifecycles and are automatically destroyed with zero disk residue (running_containers=0).

📜 Verifiable Cryptographic Proofs

Every execution emits sealed SHA-256 digests of the repository subtree, execution manifest, and output envelopes. Historical green proofs are independently auditable.

⚡ Root-Owned Broker Socket

The socket sandbox-broker-v1.sock is owned by root:prometheus with permission 0660. Arbitrary users cannot spawn containers.

🛡️ Human Agency Boundary

Two distinct human authorization gates: (1) Execution authorization before container runs, and (2) Adoption authorization before any capability is accepted into the codebase.

# Project Title
PROMETHEUS: Blast Radius Zero AI Agent Sandbox

## Elevator Pitch
Zero-blast-radius autonomous agent containment pipeline bounded by Vultr Serverless Inference and sealed cryptographic proof. Discovery is not authority.

## Challenge Category
Vultr Hackathon · Challenge 1: Blast Radius Zero

## What It Does & Problem It Solves
When autonomous AI agents evaluate untrusted repositories and code, inspection is completely decoupled from execution. Every run is governed by least privilege, strict time, memory, and network bounds via Vultr Serverless Inference, human authorization gates, ephemeral container isolation, SHA-256 evidence manifests, and real-time containment of adversarial egress and file tampering.

Our thesis: discovery is not authority. PROMETHEUS turns agent containment into a verifiable governance property, not a promise.

## Live Vultr Infrastructure (São Paulo)
- Vultr Cloud Compute (vc2-1c-1gb) in São Paulo region (sao).
- Zero public listening TCP ports (ss -tlpn verified).
- Local Broker IPC: /run/prometheus-playground/sandbox-broker-v1.sock (mode 0660 root:prometheus).
- Vultr Serverless Inference: Untrusted code discovery bounded at $0.000259/run.
