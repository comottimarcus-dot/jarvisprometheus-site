Why this matters

Most agent demos optimize for what an agent can do. Playground demonstrates how an agent can learn a new capability while keeping the path to execution narrow, reviewable and reversible.

The business question is simple: can an organization let an agent experiment without silently expanding its authority?

What this proof establishes

A signed one-shot container canary completed on the Vultr node, its exact replay was denied and the post-run audit found no lingering canary process or public Docker listener.

It does not yet claim automatic GitHub adoption, arbitrary repository execution or production readiness. Those remain behind later gates.
